# Gerenciador de Tarefas (Terminal)

Programa em Python para gerenciar tarefas pelo terminal.

## Funcionalidades
- Adicionar, listar, concluir e remover tarefas
- As tarefas ficam salvas em um arquivo JSON

## Como rodar
1. Tenha o Python 3 instalado
2. Rode: python tarefas.py

## O que aprendi
- Funções, listas e dicionários
- Leitura e escrita de arquivos JSON
- Tratamento de erros com try/except
